# الدراسة في السعودية 🇸🇦

موقع ويب متكامل للتقديم للدراسة في المملكة العربية السعودية، يقدم معلومات شاملة عن الجامعات والتخصصات والمنح الدراسية ومتطلبات القبول.

## 🌟 المميزات

- **تصميم عصري وجذاب** - واجهة عربية بالكامل (RTL) مع تأثيرات بصرية متقدمة
- **جامعات مرموقة** - معلومات عن أفضل الجامعات السعودية
- **تخصصات متنوعة** - أكثر من 200 تخصص أكاديمي
- **منح دراسية** - فرص تمويل للطلاب الدوليين
- **متطلبات القبول** - شروط القبول للبكالوريوس والماجستير والدكتوراه
- **آراء الطلاب** - تجارب حقيقية من طلاب درسوا في السعودية
- **أسئلة شائعة** - إجابات على الأسئلة الأكثر شيوعاً
- **نموذج تقديم** - نموذج شامل للتقديم عبر الموقع
- **تصميم متجاوب** - يعمل على جميع الأجهزة (موبايل/تابلت/كمبيوتر)

## 🚀 التقنيات المستخدمة

- **HTML5** - هيكل الصفحة
- **CSS3** - التصميم والتنسيقات (Flexbox, Grid, Animations)
- **JavaScript** - التفاعلات والبرمجة
- **Google Fonts** - خط Tajawal العربي
- **GitHub Pages** - الاستضافة

## 📋 متطلبات التشغيل

لا يحتاج الموقع إلى أي متطلبات خاصة، يمكنك فتحه مباشرة في أي متصفح حديث:

1. افتح ملف `index.html` في المتصفح
2. أو قم بزيارة الرابط المباشر على GitHub Pages

## 🛠️ التثبيت المحلي (اختياري)

إذا كنت تريد تشغيل الموقع محلياً:

```bash
# استنساخ المستودع
git clone https://github.com/alasasacademy-crypto/study-in-saudi.git

# الانتقال إلى مجلد المشروع
cd study-in-saudi

# فتح الموقع في المتصفح
start index.html
```
